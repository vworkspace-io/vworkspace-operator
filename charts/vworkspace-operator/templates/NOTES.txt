vWorkspace Operator has been installed.

Release: {{ .Release.Name }}
Namespace: {{ .Release.Namespace }}
Deployment: {{ include "vworkspace-operator.fullname" . }}

1. Wait for the operator pod to become Ready:

  kubectl -n {{ .Release.Namespace }} rollout status deploy/{{ include "vworkspace-operator.fullname" . }} --timeout=180s

2. Verify CRDs are registered:

  kubectl get crd applicationinstances.apps.vworkspace.io clusters.ops.vworkspace.io operations.ops.vworkspace.io

3. Register this cluster with vWorkspace Server (one-time token exchange):

  kubectl -n {{ .Release.Namespace }} exec deploy/{{ include "vworkspace-operator.fullname" . }} -- \
    /manager register \
      --token=<one-time-token> \
      --control-plane-endpoint=https://your-server.example.org \
      --cluster-name=<cluster-id>

  Or apply a Cluster CR — see docs/install/cluster-bootstrap.md.

  Registration writes Secret/{{ .Values.agent.credentialsSecret }} in this namespace.

{{- if not .Values.agent.enabled }}

4. Enable Pull-mode after registration (Helm upgrade):

  helm upgrade {{ .Release.Name }} {{ .Chart.Name }} \
    -n {{ .Release.Namespace }} \
    --reuse-values \
    --set agent.enabled=true \
    --set agent.controlPlaneBaseUrl=https://your-server.example.org
{{- else }}

4. Pull-mode agent is enabled. Ensure Secret/{{ .Values.agent.credentialsSecret }} exists
   (created during registration) or set agent credentials via flags before enabling the agent.
{{- end }}
