1. Wait for the operator pod to become Ready:

  kubectl -n {{ .Release.Namespace }} rollout status deploy/{{ include "vworkspace-operator.fullname" . }} --timeout=180s

2. Verify CRDs are registered:

  kubectl get crd applicationinstances.apps.vworkspace.io clusters.ops.vworkspace.io operations.ops.vworkspace.io

3. Connect this cluster to vWorkspace Server (declarative golden path):

  # Edit placeholders in examples/cluster-bootstrap/ (paths relative to chart root), then:
  kubectl apply -f examples/cluster-bootstrap/registration-token.secret.yaml
  kubectl apply -f examples/cluster-bootstrap/cluster.yaml

  The Cluster reconciler exchanges the token, writes Secret/{{ .Values.agent.credentialsSecret }},
  and the Pull-mode agent starts automatically when credentials exist.

  Break-glass (debug only):

  kubectl -n {{ .Release.Namespace }} exec deploy/{{ include "vworkspace-operator.fullname" . }} -- \
    /manager register \
      --token=<one-time-token> \
      --control-plane-endpoint=https://your-server.example.org \
      --cluster-name=<cluster-id>

  See docs/install/cluster-bootstrap.md.

4. Watch connectivity converge:

  kubectl get cluster -w
