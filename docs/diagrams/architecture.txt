Key properties
--------------
- One operator per cluster. The cluster boundary is the trust boundary.
- The same CRDs (ApplicationInstance, Operation) and the same in-cluster
  reconciliation loop run in every connectivity mode. Only the transport
  between Odoo and the cluster changes.
- Odoo never holds a kubeconfig in the default Pull-mode deployment.
- An Odoo outage does not take down running applications; the operator
  keeps reconciling the last applied desired state.
